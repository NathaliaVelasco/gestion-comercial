## Cómo se ve una propuesta

Cada propuesta es una página web que se recorre bajando, con un menú de secciones fijo arriba. Se puede enlazar directo a una sección con `#inversion`, `#beneficios`, etc.

## Agregar una propuesta nueva

1. Crear la carpeta `propuestas/<cliente>-<proyecto>/` con su `index.html` e `img/`.
2. Agregar una tarjeta en `propuestas/index.html` y una fila en la tabla de arriba.

> Nota: este repositorio es público. Las páginas llevan `noindex` para que los buscadores no las muestren, pero cualquier persona con el enlace o que visite el repositorio puede verlas.
